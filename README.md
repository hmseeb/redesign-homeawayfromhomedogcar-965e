# GACHA99 — Home Away From Home (Redesign)

Website statis hasil redesign untuk **GACHA99 Home Away From Home** — pusat untuk menjelajahi
game online, slot, mode demo, program bonus, serta prediction market dalam satu akses.

## Stack
Vanilla HTML, CSS, dan JavaScript. Tanpa build step, tanpa dependency, tanpa environment variable.

## Struktur
- `index.html` — halaman utama (semantic HTML, meta tags, JSON-LD)
- `styles.css` — sistem desain: token warna, komponen, layout responsif
- `script.js` — navigasi mobile, sticky header, scroll-spy, scroll reveal, back-to-top
- `favicon.svg` — favicon placeholder

## Menjalankan secara lokal
Buka `index.html` di browser, atau jalankan server statis:

```bash
python3 -m http.server 8000
```

Lalu buka http://localhost:8000
